⑥ Q-table vs DQN ทำไมต้องใช้ Neural Network?

Q-table (tabular)–ค่า = จำนวน state × 4 actions · เก็บค่าแยกทุกช่อง เรียนรู้ช่องไหนได้ช่องนั้น
DQN (network นี้)–พารามิเตอร์ (weights + biases) · ประมาณ Q(s,a) ด้วยฟังก์ชันเดียว

หมายเหตุ: maze นี้เล็ก และ input เป็น one-hot ของตำแหน่ง Q-table จึงเล็กกว่า network ด้วยซ้ำ ตัวอย่างนี้ใช้เพื่อแสดง กลไกของ DQN (network, replay, target network) ข้อได้เปรียบจริงของ DQN มาเมื่อ state ใหญ่มากหรือต่อเนื่อง เช่นภาพ 84×84×4 ใน Atari มีจำนวน state ที่เป็นไปได้มหาศาลจนเก็บเป็นตารางไม่ได้ (Curse of Dimensionality) network จะ generalize ไปยัง state ที่คล้ายกันแม้ไม่เคยเห็นมาก่อน · ลองกด ✏️ แก้กำแพงหลังฝึกเสร็จ แล้วดูว่า agent ปรับตัวอย่างไร
