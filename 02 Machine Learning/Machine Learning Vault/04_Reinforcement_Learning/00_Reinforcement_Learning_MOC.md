# 🤖 Reinforcement Learning (การเรียนรู้แบบเสริมกำลัง)

**นิยาม:** การเรียนรู้ผ่านการลองผิดลองถูก (Trial and Error) ในสภาพแวดล้อมที่กำหนด โดย Agent จะทำการตัดสินใจและได้รับผลตอบกลับเป็น "รางวัล (Reward)" หรือ "บทลงโทษ (Penalty)" เพื่อปรับปรุงนโยบาย (Policy) ให้ได้รางวัลรวมสูงสุด

---

## 🗂️ การประยุกต์ใช้งาน (Applications)
- [[Real-time decisions]] (การตัดสินใจแบบเรียลไทม์ เช่น ยานยนต์ไร้คนขับ)
- [[Game AI]] (ปัญญาประดิษฐ์ในเกม เช่น หมากรุก, AlphaGo)
- [[Skill Acquisition]] (การเรียนรู้ทักษะใหม่ๆ ของหุ่นยนต์)
- [[Learning Tasks]] (การเรียนรู้เพื่อจัดการงานอัตโนมัติ)
- [[Robot Navigation]] (การนำทางและการเคลื่อนที่ของหุ่นยนต์)

---

## 🔑 องค์ประกอบสำคัญ (Core Concepts)
- **Agent:** ตัวกระทำ หรือโปรแกรมที่ทำหน้าที่ตัดสินใจ
- **Environment:** สภาพแวดล้อมที่ Agent อาศัยอยู่และโต้ตอบด้วย
- **State (S):** สถานะปัจจุบันของ Environment
- **Action (A):** การกระทำที่ Agent เลือกทำในสถานะนั้นๆ
- **Reward (R):** รางวัลหรือผลตอบแทนที่ได้รับหลังจากทำ Action
- **Policy ($\pi$):** นโยบายหรือกลยุทธ์ที่ Agent ใช้เลือก Action
