# Dimensionality Reduction

จากบทที่ 8 Dimensionality Reduction

## ทำไมต้องลดมิติข้อมูล?
- **Curse of Dimensionality:** เมื่อจำนวนฟีเจอร์เพิ่มขึ้น ข้อมูลจะกระจัดกระจายและห่างกันมากในพื้นที่หลายมิติ ทำให้โมเดลเกิด Overfitting ได้ง่าย
- **ลดเวลา/พื้นที่:** ข้อมูลที่น้อยลงช่วยให้โมเดล Train เร็วขึ้น เปลือง RAM น้อยลง
- **Data Visualization:** ลดเหลือ 2-3 มิติเพื่อให้มองเห็นเป็นภาพและเข้าใจข้อมูลได้ง่ายเพื่อนำไปอธิบายต่อ

## เทคนิคหลัก (Main Approaches)
1. **Projection:** หาแกนหรือระนาบ (Hyperplane) ที่สะท้อนข้อมูลได้ดีที่สุด แล้วฉายข้อมูลลงบนระนาบนั้น (เหมือนมองเงาบนผนัง)
2. **Manifold Learning:** พยายามคลี่คลายข้อมูลที่บิดเบี้ยวอยู่ในพื้นที่หลายมิติ (เช่น Swiss roll) ออกมาเป็นระนาบแบนๆ

## อัลกอริทึมที่สำคัญ

### 1. Principal Component Analysis (PCA)
- เป็นเทคนิคแบบ Projection ที่นิยมที่สุด
- พยายามหาแกน (Principal Component) ที่รักษา **ความแปรปรวน (Variance)** ของข้อมูลไว้ให้มากที่สุด
- แกนแรกจะรักษา Variance มากที่สุด แกนที่สองจะตั้งฉากกับแกนแรกและเก็บ Variance ที่เหลือให้มากที่สุด เป็นเช่นนี้ไปเรื่อยๆ

**ตัวอย่างโค้ด PCA (Scikit-Learn)**
```python
from sklearn.decomposition import PCA

# ลดให้เหลือแค่มิติที่สามารถเก็บ Variance ไว้ได้ 95%
pca = PCA(n_components=0.95)
X_reduced = pca.fit_transform(X_train)
```

### 2. Locally Linear Embedding (LLE)
- เป็นเทคนิคแบบ Manifold Learning ที่ทรงพลัง
- ไม่ได้ฉายภาพ แต่ใช้วิธีวัดความสัมพันธ์ระหว่างจุดข้อมูลแต่ละจุดกับจุดรอบข้าง (Neighbors) แล้วพยายามสร้างพื้นที่ในมิติที่ต่ำกว่าโดยยังคงความสัมพันธ์เดิมเอาไว้
- เหมาะมากสำหรับการ "คลี่" ข้อมูลที่ซับซ้อนอย่างม้วนแยม (Swiss Roll)
