# 🧩 Unsupervised Learning (การเรียนรู้แบบไม่มีผู้สอน)

**นิยาม:** การเรียนรู้จากข้อมูลที่ไม่มีฉลากคำตอบ (Unlabeled data) โดยให้อัลกอริทึมค้นหาโครงสร้าง รูปแบบ หรือความสัมพันธ์ที่ซ่อนอยู่ด้วยตัวเอง

---

## 🗂️ หมวดหมู่หลัก

### 1. Clustering (การจัดกลุ่ม)
*การแบ่งกลุ่มข้อมูลที่มีลักษณะคล้ายคลึงกันให้อยู่ด้วยกัน*
- **ตัวอย่างการประยุกต์ใช้:**
  - [[Recommender Systems]] (ระบบแนะนำสินค้า/เนื้อหา)
  - [[Targeted Marketing]] (การทำการตลาดแบบเจาะจงเป้าหมาย)
  - [[Customer Segmentation]] (การแบ่งส่วนตลาด/แบ่งกลุ่มลูกค้า)

### 2. Dimensionality Reduction (การลดมิติข้อมูล)
*การลดจำนวนตัวแปรโดยพยายามรักษาข้อมูล/ความแปรปรวนที่สำคัญไว้*
- **ตัวอย่างการประยุกต์ใช้:**
  - [[Meaningful Compression]] (การบีบอัดข้อมูลอย่างมีความหมาย)
  - [[Structure Discovery]] (การค้นพบโครงสร้างของข้อมูล)
  - [[Big Data Visualisation]] (การแสดงผลข้อมูลขนาดใหญ่)
  - Feature Elicitation (การสกัดคุณลักษณะเด่น)
