เป็นการแบ่งกลุ่มข้อมูลที่มีความคล้ายคลึงกันให้อยู่ใน Cluster เดียวกัน โดยที่เราไม่มี Label หรือคำตอบไว้ล่วงหน้าเลย

## K-Means Algorithm
- อัลกอริทึมยอดฮิต ทำงานเร็ว และมีประสิทธิภาพสูงสำหรับกลุ่มที่มีลักษณะเป็นทรงกลม (Spherical) และขนาดใกล้เคียงกัน
- **การทำงาน:**
  1. สุ่มวางจุดศูนย์กลาง (Centroids) $k$ จุด
  2. กำหนดให้ข้อมูลแต่ละตัวอยู่ในกลุ่มของ Centroid ที่ใกล้ที่สุด
  3. คำนวณหาค่าเฉลี่ยของข้อมูลในแต่ละกลุ่ม เพื่อปรับตำแหน่งของ Centroid ใหม่
  4. ทำซ้ำขั้นตอนที่ 2 และ 3 ไปเรื่อยๆ จนกว่า Centroid จะไม่ขยับอีก

- **จุดอ่อน:** คุณต้องกำหนดจำนวนกลุ่ม ($k$) ไว้ล่วงหน้า และผลลัพธ์อาจจะเพี้ยนได้ถ้าสุ่มจุดเริ่มต้นไม่ดี หรือถ้ากลุ่มข้อมูลมีขนาด รูปร่าง และความหนาแน่นต่างกันมากๆ
- เรามักใช้ **Inertia** (ระยะทางเฉลี่ยยกกำลังสองจากข้อมูลไปหา Centroid) หรือ **Silhouette Score** เพื่อช่วยหาค่า $k$ ที่เหมาะสมที่สุด

**ตัวอย่างโค้ด K-Means (Scikit-Learn)**
```python
from sklearn.cluster import KMeans

k = 5
kmeans = KMeans(n_clusters=k)
y_pred = kmeans.fit_predict(X)

# ดูจุดศูนย์กลาง
print(kmeans.cluster_centers_)
```

## DBSCAN
- เป็นอัลกอริทึมที่หาพื้นที่ที่มี "ความหนาแน่นสูง" (High density) อย่างต่อเนื่องกัน
- **ข้อดี:** ไม่ต้องกำหนด $k$ ล่วงหน้า, ค้นหากลุ่มข้อมูลที่มีรูปร่างแปลกๆ ได้ดีเยี่ยม, และทนทานต่อ Outliers สูง
- ควบคุมด้วยพารามิเตอร์ `eps` (ระยะทางเพื่อนบ้าน) และ `min_samples` (จำนวนขั้นต่ำเพื่อเป็น Core instance)
