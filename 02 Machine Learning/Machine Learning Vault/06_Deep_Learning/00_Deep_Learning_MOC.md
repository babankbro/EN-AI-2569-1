# 🧠 Deep Learning Map of Content (MOC)

ยินดีต้อนรับสู่หมวดหมู่ Deep Learning (การเรียนรู้เชิงลึก)
ในส่วนนี้จะครอบคลุมเนื้อหาเกี่ยวกับโครงข่ายประสาทเทียม (Neural Networks) และสถาปัตยกรรมเชิงลึกต่างๆ

## 🗂️ หัวข้อหลัก

1. **[[Artificial_Neural_Networks|สถาปัตยกรรมโครงข่ายประสาทเทียมพื้นฐาน (ANNs)]]**
   - Perceptron, Multi-Layer Perceptron (MLP)
   - การใช้งาน Keras เบื้องต้น (Sequential API, Functional API)
2. **[[Training_Deep_Neural_Networks|การฝึกสอนโมเดลเชิงลึก (Training DNNs)]]**
   - ปัญหา Vanishing/Exploding Gradients และวิธีแก้
   - Optimizers (Momentum, RMSProp, Adam)
   - Regularization (Dropout)
3. **[[Convolutional_Neural_Networks|โครงข่ายประสาทเทียมแบบคอนโวลูชัน (CNNs)]]**
   - Convolutional Layer, Pooling Layer
   - สถาปัตยกรรมดังๆ (LeNet-5, AlexNet, ResNet)
   - การประยุกต์ใช้ (Object Detection, Semantic Segmentation)

## 🔗 เครื่องมือและไลบรารี
- **TensorFlow & Keras:** เครื่องมือหลักในการสร้างและฝึกสอน Deep Learning โมเดล
