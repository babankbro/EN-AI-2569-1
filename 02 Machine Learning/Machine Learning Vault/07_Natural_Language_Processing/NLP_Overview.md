# Natural Language Processing (NLP)

**NLP** ย่อมาจาก **Natural Language Processing**
แปลเป็นภาษาไทยคือ **"การประมวลผลภาษาธรรมชาติ"**

## ความหมาย
คือสาขาหนึ่งของปัญญาประดิษฐ์ (AI) ที่ทำให้คอมพิวเตอร์สามารถ **"เข้าใจ, ตีความ, และสร้าง"** ภาษามนุษย์ (ภาษาธรรมชาติที่เราใช้สื่อสารกัน เช่น ภาษาไทย ภาษาอังกฤษ) ได้อย่างมีความหมาย 

พูดง่ายๆ คือเป็นการทำให้คอมพิวเตอร์สามารถสื่อสารและเข้าใจภาษาของคนได้เหมือนที่คนคุยกันเอง

## ตัวอย่างการใช้งาน NLP ในชีวิตประจำวัน
* **Chatbot หรือผู้ช่วยเสมือน:** เช่น ChatGPT, Siri, Google Assistant ที่เราสามารถพิมพ์หรือพูดคุยด้วยได้
* **การแปลภาษา:** เช่น Google Translate ที่เข้าใจรูปประโยคและแปลข้ามภาษาได้
* **ระบบแก้ไขคำผิดและแนะนำคำ (Auto-correct/Auto-complete):** ในแป้นพิมพ์มือถือหรือโปรแกรมพิมพ์งาน
* **การวิเคราะห์ความรู้สึก (Sentiment Analysis):** คอมพิวเตอร์สามารถอ่านรีวิวสินค้าและบอกได้ว่าคนส่วนใหญ่ชมหรือด่า (รู้สึกบวกหรือลบ)
* **การสรุปข้อความ (Text Summarization):** ให้คอมพิวเตอร์อ่านบทความยาวๆ แล้วย่อสรุปใจความสำคัญให้สั้นลง
