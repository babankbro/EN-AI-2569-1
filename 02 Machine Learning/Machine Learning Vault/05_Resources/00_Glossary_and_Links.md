# 📚 Resources & Glossary (แหล่งข้อมูลและคำศัพท์)

พื้นที่สำหรับรวบรวมคำศัพท์เฉพาะทาง, เครื่องมือ, ชุดข้อมูล, และลิงก์สำหรับศึกษาเพิ่มเติม

---

## 📖 สมุดคำศัพท์ (Glossary)
*(อัปเดตคำศัพท์ใหม่ๆ ที่คุณเจอได้ที่นี่ หรือสร้างเป็นโน้ตแยกต่างหาก)*

- **Algorithm (อัลกอริทึม):** ลำดับขั้นตอนหรือชุดคำสั่งทางคณิตศาสตร์ที่ใช้ในการแก้ปัญหาหรือเรียนรู้จากข้อมูล
- **Model (โมเดล):** ระบบที่ผ่านการฝึกสอน (Train) จากข้อมูลเรียบร้อยแล้ว พร้อมนำไปใช้ทำนายผล
- **Dataset (ชุดข้อมูล):** กลุ่มของข้อมูลที่ถูกรวบรวมไว้สำหรับใช้สอน (Train) หรือทดสอบ (Test) โมเดล
- **Feature (คุณลักษณะ/ตัวแปร):** คุณสมบัติต่างๆ ของข้อมูลที่นำมาใช้เป็น Input ให้กับโมเดล
- **Label / Target (ฉลาก/เป้าหมาย):** ผลลัพธ์หรือคำตอบที่เราต้องการให้โมเดลทายให้ถูก (ใช้ใน Supervised Learning)
- **Overfitting:** ภาวะที่โมเดลจำข้อมูลสอนได้ดีเกินไป แต่ไม่สามารถนำไปใช้ทำนายข้อมูลใหม่ได้ดี
- **Underfitting:** ภาวะที่โมเดลเรียบง่ายเกินไป ไม่สามารถเรียนรู้รูปแบบจากข้อมูลได้
- **Hyperparameter:** พารามิเตอร์ของ "อัลกอริทึม" ที่เราต้องกำหนดก่อนเริ่มสอนโมเดล (ต่างจาก Parameter ที่โมเดลเรียนรู้เอง)
- **Cross-Validation:** เทคนิคการประเมินโมเดลโดยการสลับส่วนของข้อมูลที่ใช้สอนและทดสอบ เพื่อให้ได้ค่าความแม่นยำที่น่าเชื่อถือ
- **Epoch:** 1 Epoch คือรอบที่โมเดลได้เรียนรู้ข้อมูล Training set ครบทั้งหมด 1 รอบพอดี
- **Batch Size:** จำนวนข้อมูลที่ถูกแบ่งป้อนเข้าไปสอนโมเดลใน 1 ครั้ง (ก่อนจะอัปเดตค่าน้ำหนัก)
