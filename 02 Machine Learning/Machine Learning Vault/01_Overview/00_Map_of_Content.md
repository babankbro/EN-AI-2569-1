# 🧠 Machine Learning Map of Content (MOC)

ยินดีต้อนรับสู่คลังความรู้ (Vault) สำหรับการเรียนรู้ Machine Learning ใน Obsidian!
คลังความรู้นี้ถูกออกแบบโครงสร้างโดยแบ่งออกเป็นส่วนหลักๆ เพื่อให้ง่ายต่อการศึกษา จัดระเบียบความคิด และเชื่อมโยงข้อมูล

## 🗂️ โครงสร้างหลัก (The Components)

1. **[[01_Overview/00_Map_of_Content|1. ภาพรวมและจุดเริ่มต้น (Overview)]]** - หน้าหลัก (MOC) นี้สำหรับดูภาพรวมทั้งหมด และ [[01_Overview/Machine_Learning_Landscape|ภาพรวมของ Machine Learning]]
2. **[[02_Supervised_Learning/00_Supervised_Learning_MOC|2. การเรียนรู้แบบมีผู้สอน (Supervised Learning)]]** - รวมโน้ตเกี่ยวกับ Classification และ Regression
3. **[[03_Unsupervised_Learning/00_Unsupervised_Learning_MOC|3. การเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning)]]** - รวมโน้ตเกี่ยวกับ Clustering และ Dimensionality Reduction
4. **[[04_Reinforcement_Learning/00_Reinforcement_Learning_MOC|4. การเรียนรู้แบบเสริมกำลัง (Reinforcement Learning)]]** - รวมโน้ตเกี่ยวกับ Agent, Environment, การประยุกต์ใช้
5. **[[06_Deep_Learning/00_Deep_Learning_MOC|5. การเรียนรู้เชิงลึก (Deep Learning)]]** - โครงข่ายประสาทเทียม (Neural Networks), CNNs
6. **[[05_Resources/00_Glossary_and_Links|6. แหล่งข้อมูลและคำศัพท์ (Resources & Glossary)]]** - รวมคำศัพท์เฉพาะทาง เครื่องมือ และลิงก์อ้างอิง

## 📝 แนวทางการใช้งาน Vault นี้
- **ใช้หน้านี้เป็นศูนย์กลาง (Hub):** เป็นจุดเริ่มต้นในการกระโดด (Link) ไปยังหัวข้อต่างๆ
- **การสร้างโน้ตใหม่:** เมื่อคุณเรียนรู้เรื่องใหม่ ให้สร้างโน้ตในโฟลเดอร์ที่ตรงกับหมวดหมู่ แล้วทำลิงก์ (`[[ชื่อโน้ต]]`) กลับมาที่หน้า MOC ของหมวดหมู่นั้นๆ
- **การใช้ Tags:** แนะนำให้ใส่ Tag ที่ท้ายโน้ตแต่ละหน้า เช่น `#machinelearning`, `#supervised`, `#deeplearning` เพื่อให้ค้นหาได้ง่ายในอนาคต
